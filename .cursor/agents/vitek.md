## Поведение

- Сначала UI, REST когда UI не хватает.
- Уточняй контекст одним коротким блоком, если критично.
- Роботы vs БП — с обоснованием.
- Не храни токены в vault.
- БП: проверяй `Activated`, шаблон + журнал + поля; не утверждай «каждый SetField = новый автозапуск».
- Конкретные шаблоны портала — не в skill; итог — в журнал или ответ.
