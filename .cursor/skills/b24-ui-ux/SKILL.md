# UX/UI Битрикс24

## Источник истины

Перед реализацией сверяй актуальную официальную документацию:

- [Bitrix24 UI Kit](https://apidocs.bitrix24.com/api-reference/widgets/ui-kit/index.html)
- [Quick Start](https://apidocs.bitrix24.com/api-reference/widgets/ui-kit/quick-start.html)
- [B24 UI components](https://bitrix24.github.io/b24ui/docs/components/)
- [bitrix24/b24ui](https://github.com/bitrix24/b24ui)

Не имитируй Б24 случайным CSS, если официальный компонент или токен уже существует.

## Выбор стека

1. Новый интерфейс приложения: **Vue 3 + Vite + официальный B24 UI Kit**.
2. Существующий интерфейс на другом стеке: используй официальные design tokens и `@bitrix24/icons`, не переписывай приложение без причины.
3. Legacy-расширения `ui.buttons`, `ui.forms`, `ui.entity-selector` применяй только там, где они реально доступны в окружении портала.

Перед добавлением пакетов проверяй актуальные имена и команды в Quick Start. Не выдумывай версии.

## UX-паттерны

- Страница: короткий заголовок, основное действие справа, контент без лишней декоративности.
- Навигация внутри приложения: компактные табы/сегменты; активный раздел очевиден.
- Формы: одна колонка по умолчанию; связанные даты можно ставить рядом; обязательность и ошибка у поля.
- Пользователи: штатный селектор сотрудников с аватаром, ФИО и подразделением; не текстовый input.
- Таблицы: фиксированный смысл колонок, статус-бейджи, действия строки в меню; фильтр и пустое состояние.
- Опасные действия: подтверждение с конкретным последствием; не полагайся только на цвет.
- Асинхронность: loading/skeleton, success, empty, error и conflict — обязательные состояния.
- Даты: показывай локальный формат портала и явно объясняй, в какой день срабатывает автоматизация.
- iframe/placement: без горизонтального скролла, адаптивная высота, компактные отступы.
- Поддерживай светлую/тёмную тему через токены, если UI Kit это предоставляет.

## Визуальный язык

- Используй типографику, цвета, радиусы, тени, интервалы и иконки B24 UI Kit.
- Не добавляй градиенты, Micra/Futura и палитру Навигатора, если пользователь просит именно нативный Б24.
- Не смешивай брендбук Навигатора и нативный стиль Б24 без явной просьбы.
- Основной цвет — через токен темы, а не захардкоженный hex.

## Процесс

1. Зафиксируй сценарии и роли пользователей.
2. Составь карту экранов и состояний.
3. Выбери готовые компоненты UI Kit.
4. Сделай wireframe/структуру до декоративной полировки.
5. Реализуй адаптивно и проверь iframe.
6. Проверь клавиатуру, фокус, контраст, ошибки и длинные ФИО.

## Граница ответственности

Дизайнер отвечает за UX, компоненты и вёрстку. REST, права, бизнес-процессы, cron и деплой согласует с Витьком.
