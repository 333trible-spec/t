# Сквозная аналитика Битрикс24 — тест и FAQ

Канон ответов на тест по сквозной аналитике (проверено на практике, июль 2026).

## Базовые понятия

| Вопрос | Ответ |
|--------|-------|
| Зачем нужна сквозная аналитика? | Оценить окупаемость рекламы, сравнить источники, определить CAC |
| Только на сайтах Б24? | **Нет** — любая платформа, где можно разместить JS |
| Call-tracking | Учёт, с какого рекламного источника звонят по телефону |
| Email-tracking | Учёт, с какого рекламного источника пишут на email |
| Оффлайн (баннеры, радио) | Отдельный номер телефона и/или email на каждый канал |
| Прочий трафик | Все обращения, не отнесённые к настроенным источникам (авто, без настройки) |

## Подключение сайтов

| Вопрос | Ответ |
|--------|-------|
| Сайты **Битрикс24** | Ничего не настраивать — уже интегрировано |
| Сайт/магазин на **любой платформе** | JS-код **виджета открытых линий** **или** JS-код **сквозной аналитики** |
| Несколько сайтов | Да, на любой платформе |
| Тематический сайт (реклама со ссылками) | Новый источник + UTM + UTM в ссылки на **ваш** сайт. Код на чужой площадке **не** нужен |

> **Важно (частая ошибка теста):** вариант «текстовый файл в корень **или** JS сквозной аналитики» — **неверный**. Правильно: «JS открытых линий **или** JS сквозной аналитики».

## Настройка

| Вопрос | Ответ |
|--------|-------|
| Базовая настройка | UTM-метки + распределить телефоны/email по источникам + разметить рекламные источники |
| Названия UTM | Произвольно, главное — понятно вам и единообразно |
| Затраты Яндекс.Директ | Автоматически (кабинет) + вручную (напр. оплата специалиста) |
| Преимущество CRM «5 из 5» | Всё встроено: обращения, call-tracking, сквозная аналитика, отчёты — без склейки систем |

## Телефония и call-tracking

| Вопрос | Ответ |
|--------|-------|
| Какие номера для call-tracking | Встроенная телефония Б24 **и** свои номера облачной АТС с интеграцией |
| Покупка номеров встроенной телефонии | По 1 шт **или** пакеты на **5** и **10** номеров (пакета на 3 нет) |

## Отчёты и метрики

| Вопрос | Ответ |
|--------|-------|
| Доступные отчёты | **«Окупаемость рекламы»** и **«Влияние трафика на продажи»** (не ABC, не RFM) |
| ROI в отчёте | **Маркетинговый ROI**; 100% = «в ноль» (только затраты на рекламу, без себестоимости) |
| ROI 65% | Канал **не окупается** (< 100%) |
| % рядом с показателем (напр. +23%) | **Изменение к предыдущему периоду** (не доля перехода по воронке) |
