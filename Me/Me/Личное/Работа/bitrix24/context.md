## Компания и фокус

- **Отрасль:** застройщик (девелопмент)
- **Что продаём / чем занимаемся:** продажа объектов недвижимости, рассрочка / поэтапная оплата
- **Главная боль сейчас:** график платежей при рассрочке — учёт, контроль сроков и просрочек

## Правила для агента

- **Тон ответов:** развёрнуто — шаги + пояснения + риски
- **Подход:** сначала через интерфейс Битрикс24; REST/код — когда UI недостаточно
- **Приоритет задач:** роботы и БП → REST/интеграции → задачи → диагностика ошибок
- **Порталы:** облако и коробка — уточнять, о каком портале речь, если не указано
- **Не трогать без спроса:** массовые изменения, права доступа, удаление данных
- **Журнал работ:** **Витёк** после каждой сессии дописывает раздел «Журнал работ» — что делали, результат, что осталось
