# «График платежей» — экспорт из монолита timereport/

Это НЕ отдельное приложение — это часть монолита `timereport/` в репозитории
`tm-reports`, вырезанная сюда для удобства (просмотреть/забэкапить/перенести).
Само по себе не запускается: используйте вместе с полным `timereport/`.

## Что внутри

| Файл | Что это | Статус |
|---|---|---|
| `payments.py` | Вся бизнес-логика: чтение сделки, генерация строк графика, сверка со счетами Битрикса, генерация документа | полная копия из `timereport/payments.py` |
| `static/schedule.html` | Фронт вкладки (форма + таблица) | полная копия |
| `app_routes_schedule.py` | Роуты `/schedule`, `/api/schedule*` | **выдержка** из `timereport/app.py` (строки 519–611), справочно — сами по себе не запустятся |
| `db_payments_snippet.py` | Таблицы `payment_schedules`/`payment_schedule_items` + функции чтения/записи | **выдержка** из `timereport/db.py`, справочно |
| `docs/grafik-platezhey.md` | Исходное ТЗ (модель графика, алгоритм сверки счетов) | как есть |
| `docs/paysched-app-design.md` | Проектный документ на переезд в маркет-приложение — решили НЕ переезжать, продукт остаётся тут | как есть |

## Зависимости, которые НЕ включены сюда (нужны из `timereport/`)

- `app.py` — сама Flask-обвязка, регистрация роутов, `_is_admin()` (проверка прав на мутирующие ручки).
- `db.py` — `get_conn()`/инициализация БД целиком (payment_schedules — лишь часть общей `timereport.db`).
- `config.py` — `BITRIX_WEBHOOK`, `PAYMENT_DOC_TEMPLATE_ID` (id шаблона генератора документов, сейчас `48`).
- Вебхук Битрикса портала dm-tmn (пользователь 44) — без него `payments.py` не сможет читать/писать сделки и счета.
- Шаблон генератора документов №48 на портале — с текстовым маркером `[[PAYMENTS_TABLE]]`.

## Как запустить как есть

Не из этой папки — из `timereport/` в основном репозитории:

```bash
cd tm-reports/timereport
PORT=5077 python3 app.py     # http://127.0.0.1:5077/schedule?deal=<id>
```

## Контекст (почему так, а не отдельным приложением)

22.07.2026 обсуждали перенос на каркас `b24-market-kit` и публикацию в
Битрикс24 Маркете (см. `docs/paysched-app-design.md`). Решение: не переезжаем —
ниша в Маркете занята (6-7 конкурирующих приложений). Сервер «Блэк холл», где
физически крутится монолит `timereport/`, тем не менее закрывается — вкладка
там перестанет работать. Но код никуда не девается, живёт в `tm-reports/timereport/`
в git; этот экспорт — то же самое, просто отдельной папкой.
