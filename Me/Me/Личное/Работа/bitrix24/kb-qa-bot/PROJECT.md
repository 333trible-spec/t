# Чат-бот по базе знаний (KB QA Bot)

Чат-бот в мессенджере **одного портала** отвечает на вопросы по статьям базы знаний **другого портала** (dm-tmn). Понимает вопросы с опечатками, пунктуацией и грамматикой. Может прикладывать скриншоты из статей.

**Отдельный проект** от [[../kb-migration/PROJECT|kb-migration]] (миграция Drive → БЗ).

## Задача

Пользователь пишет боту в мессенджере → бот ищет ответ в папке [document/74 «Битрикс24»](https://dm-tmn.bitrix24.ru/note/document/74/) на dm-tmn → отвечает текстом, при необходимости — картинками и ссылкой на статью.

## Решения (зафиксировано 2026-07-01)

| Параметр | Значение |
|----------|----------|
| Портал бота | **b24-s2an91** (тест) |
| Источник БЗ | **dm-tmn**, только папка **document/74** |
| Картинки | **Автоматически**, если в статье есть скрины по теме |
| Аудитория | Все сотрудники портала с ботом |
| LLM | **Бесплатно** (Ollama на ПК / Gemini free tier — уточнить при старте) |
| Сервер (тест) | Локально + **ngrok** (как crm-report-bot); прод — VPS |

## Архитектура

```
b24-s2an91 (мессенджер, imbot v2)
    ↔ kb-qa-bot (HTTPS handler)
        ↔ dm-tmn: note.document.tree.list + note.document.get (папка 74)
        ↔ note.file.* — скачать картинки из статей
        ↔ LLM (RAG: релевантные фрагменты + ответ)
        ↔ кэш текстов и изображений (синк по cron)
        → imbot.v2.Chat.Message.send + imbot.v2.File.upload (скрины)
```

### Два REST-подключения

| Роль | Портал | Scope |
|------|--------|-------|
| Чтение БЗ | dm-tmn | `note`, `disk` — вебхук `B24_KB_WEBHOOK` ([[../kb-migration/context|kb-migration/.env]]) |
| Чат-бот | b24-s2an91 | `imbot`, `im` — отдельный вебхук + `B24_BOT_ID`, `B24_BOT_TOKEN` |

### Картинки (кросс-портал)

Прямая ссылка на dm-tmn в `IMAGE.LINK` **не работает** без сессии. Варианты:

1. **`imbot.v2.File.upload`** — скачать байты через `note.file.*`, отправить base64 в чат бота ✅
2. **Кэш на сервере** — при синке сохранить PNG, отдавать по HTTPS в `attach IMAGE`

### LLM (бесплатно)

1. **Ollama** на ПК — без лимитов, модели `llama3` / `qwen2.5`
2. **Google Gemini** — free tier, нужен API-ключ
3. **Запасной** — полнотекстовый поиск по кэшу; LLM только если мало совпадений

## Ограничения

- Свежесть ответов зависит от интервала синка БЗ
- Ссылки на dm-tmn откроются только у тех, у кого есть доступ к той БЗ
- REST dm-tmn ~2 req/s — синк пакетами, не на каждый вопрос
- Промпт: отвечать только по контексту статей; иначе «не знаю»
