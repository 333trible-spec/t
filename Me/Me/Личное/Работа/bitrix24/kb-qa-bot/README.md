## Быстрый старт (когда будет код)

1. Скопировать `.env.example` → `.env`
2. Вебхук dm-tmn — из `kb-migration/.env` или общий `bitrix24/.env`
3. `npm start` + ngrok → `B24_HANDLER_URL`
4. `npm run register`
5. Мессенджер b24-s2an91 → написать боту вопрос по инциденту Б24
