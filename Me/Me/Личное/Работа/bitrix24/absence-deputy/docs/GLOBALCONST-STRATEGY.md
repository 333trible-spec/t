## Вариант 3 — PHP в БП (текущий фокус)

### Идея

Служебный шаблон БП с активити **«PHP-код»** на портале:

1. Параметры запуска: `ConstId`, `NewUserId` (или один `TargetUser` + карта констант).
2. PHP: загрузить свойство константы, выставить `Default` = `user_{ID}`, сохранить через `GlobalConst::upsert`.
3. Запуск из «6 кадров»: `bizproc.workflow.start` (scope `bizproc`) на документ-заглушку (сделка / lists).

### Тестовая константа

| Название | ID |
|----------|-----|
| **Проджект Б24** | `Constant1726726681045` |

### Риск облака

Активити **«PHP-код»** на **облачном** Б24 часто **недоступно** (только коробка). Перед разработкой — проверка на ik-navigator:

1. Дизайнер БП → добавить действие → есть ли **«PHP-код»**?
2. Скрипт: `node scripts/scan-php-activities.mjs` — есть ли `CodeActivity` / `Php` в существующих шаблонах?

**Проверка 2026-07-20:** по ~126 типам активити во всех шаблонах портала **PHP/Code не найдено** — плохой знак для варианта 3, но финально решает наличие пункта в палитре дизайнера.

Если PHP на портале **нет** → сразу переходим к **варианту 5** (маркет).
