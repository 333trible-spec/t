# CRM Report Bot — чат-бот Битрикс24



Внутренний чат-бот для **тестового** портала: отчёты по лидам и сделкам из CRM по командам в мессенджере.



## Команды бота



| Команда | Отчёт |

|---------|--------|

| `отчет` | Сводка за 7 дней |

| `отчет 30` | Сводка за 30 дней |

| `отчет лиды` | Лиды по стадиям |

| `отчет сделки` | Сделки воронки «Продажа недвижимости» |

| `помощь` | Список команд |



## Архитектура



```

Мессенджер Б24 → ONIMBOTMESSAGEADD → server.js (handler)

                                         ↓

                                   CRM REST (crm.lead.list, crm.deal.list)

                                         ↓

                                   imbot.message.add → ответ в чат

```



## Быстрый старт (тест b24-s2an91)



### 1. Вебхук



Используется **существующий** входящий вебхук из `Личное/Работа/bitrix24/.env` → `B24_TEST_WEBHOOK` (все нужные права уже выданы). Новый вебхук создавать не нужно.



Сервер и `register` подхватывают `.env` автоматически (`lib/load-env.js`).



### 2. Публичный URL обработчика



Бот в облаке Б24 шлёт события на **HTTPS**. Локально:



```powershell

cd "Личное/Работа/bitrix24/crm-report-bot"

npm start

# В другом терминале — туннель, например ngrok:

# ngrok http 3847

```



Путь обработчика: `https://ВАШ-ТУННЕЛЬ/bitrix/handler`



### 3. Регистрация бота



```powershell

$env:B24_HANDLER_URL = "https://xxxx.ngrok-free.app/bitrix/handler"

npm run register

```



Скопируйте `B24_BOT_ID` в `crm-report-bot/.env` или в общий `.env`.



### 4. Проверка



Мессенджер → **CRM Отчёты** (бот) → `отчет`



## Файлы



| Файл | Назначение |

|------|------------|

| `server.js` | HTTP-сервер, приём событий Б24 |

| `lib/load-env.js` | Читает `../.env` (B24_TEST_WEBHOOK) |

| `lib/reports.js` | Сбор отчётов из CRM |

| `lib/bot-handler.js` | Разбор команд и ответ |

| `scripts/register-bot.js` | `imbot.register` |



## Ограничения



- Только портал из `.env`; прод **ik-navigator** не трогать без согласования

- Отчёты — агрегаты по `DATE_CREATE`, воронка сделок `CATEGORY_ID=1`

- Для продакшена: VPS + HTTPS, локальное приложение вместо вебхука, кэш и лимиты REST
