Бот в мессенджере: **CRM Отчёты**  
Проект: `Личное/Работа/bitrix24/crm-report-bot/`

---

## Включить / выключить бота на компьютере

Бот работает **только пока на ПК запущен** `node server.js`.  
Когда выключен — **никаких процессов и нагрузки на ПК нет** (в Б24 карточка бота остаётся, но ответов не будет).

### Включить

PowerShell:

```powershell
cd "Личное\Работа\bitrix24\crm-report-bot"
.\scripts\start-bot.ps1
```

Или двойной клик по `scripts\start-bot.ps1` (если разрешены скрипты).

### Выключить

```powershell
cd "Личное\Работа\bitrix24\crm-report-bot"
.\scripts\stop-bot.ps1
```

Процесс Node завершается полностью — CPU, память и опрос API Б24 прекращаются.

### Проверить статус

```powershell
.\scripts\status-bot.ps1
```

| Статус | Значение |
|--------|----------|
| **ВКЛЮЧЁН** | Бот отвечает в мессенджере (задержка до ~10 сек) |
| **ВЫКЛЮЧЕН** | ПК не нагружается, бот в чате молчит |

### Альтернатива (окно терминала)

```powershell
npm start
```

Остановка: **Ctrl+C** в этом окне — то же, что выключить бота.

## Команды боту в мессенджере

Пишите в **личный чат** с ботом «CRM Отчёты».  
В **групповом чате** — только с упоминанием **@CRM Отчёты**.

| Команда | Что делает |
|---------|------------|
| `помощь` | Список команд |
| `отчет` | Сводка за **7 дней** (лиды + сделки) |
| `отчет 30` | Сводка за **30 дней** (число 1–365) |
| `отчет лиды` | Лиды по стадиям за 7 дней |
| `отчет лиды 14` | Лиды за 14 дней |
| `отчет сделки` | Сделки воронки «Продажа недвижимости» за 7 дней |
| `отчет сделки 30` | Сделки за 30 дней |
| `сводка` | То же, что `отчет` |

Примеры:

```
отчет
отчет 30
отчет лиды
отчет сделки 14
помощь
```

## Как это устроено

- Режим **fetch**: сервер на ПК раз в ~10 секунд спрашивает Б24 «есть ли новые сообщения».
- **Туннель (ngrok/cloudflared) не нужен** — только `npm start` или `start-bot.ps1`.
- Секреты: `Личное/Работа/bitrix24/.env` (`B24_TEST_WEBHOOK`) и `crm-report-bot/.env` (`B24_BOT_ID`, `B24_BOT_TOKEN`).

---

## Если бот не отвечает

1. `.\scripts\status-bot.ps1` — включён ли процесс?
2. Если выключен → `.\scripts\start-bot.ps1`
3. В мессенджере: личный чат с ботом, не группа без @
4. Лог ошибок: `server.err.log` в этой папке
