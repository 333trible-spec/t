# Заявка на договор — кратко

**Где:** CRM → сделка → вкладка **«Заявка на договор»**. Внутри вкладки: **?** рядом с версией.

**Когда**

| Ситуация | Режим |
|----------|--------|
| **Продажи** | Полный |
| **Оформление** | Только просмотр |
| Сделка успешно закрыта | Смотреть можно, менять нельзя |

**Шаги:** проверить данные → заполнить * → документы → **Проверить** → **Сохранить** или **Отправить**.

**Документы:** несколько файлов — Ctrl/Shift. Удалить — крестик на карточке → **Сохранить**.

**Отправить** активна при заполненных обязательных полях и данных покупателя (ФИО, телефон, почта, реквизиты).
