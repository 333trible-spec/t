# Заявка на договор — кратко для сотрудников

**Где:** CRM → сделка → вкладка **«Заявка на договор»** (ik-navigator). Если не видно — **⋯** / **Ещё**.

**Когда работает:** в воронке **Продажи** — полный режим. В **Оформлении** — только просмотр.

---

**Что делать**

1. Откройте вкладку, проверьте подставленные данные.
2. Заполните обязательные поля (*), прикрепите документы.
3. Проверьте контакт: **ФИО, телефон, почта, реквизиты** (карточка контакта кликабельна).
4. **Проверить** — покажет, чего не хватает.
5. **Сохранить** — записать в сделку без отправки.
6. **Отправить** — передать в оформление.

**При отправке** появится: *«Передаю в оформление. Не закрывайте окно»* — дождитесь окончания, окно не закрывайте.

**Отправить** активна, когда заполнены все обязательные поля и данные контакта.

---

**Если не получается**

- Кнопка серая → **Проверить**, исправить замечания.
- Нет вкладки → нет доступа к приложению или сделке (администратор).
- В оформлении нельзя редактировать → так задумано, правки в сделке продаж.

Полная инструкция: `docs/USER-GUIDE.md`
