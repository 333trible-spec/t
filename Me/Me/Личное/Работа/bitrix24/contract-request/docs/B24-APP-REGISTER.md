# Регистрация локального приложения — Заявка на договор

Портал: **только** https://ik-navigator.bitrix24.ru/ (не b24-s2an91).

После `npm run deploy` URL — в `../static-urls.json`.

## 1. Хостинг

Разместить `app/public/` на HTTPS (Vercel / GitHub Pages / свой домен).  
Пример базового URL: `https://contract-request.vercel.app`

| Файл | URL |
|------|-----|
| **Обработчик** (открытие из Маркета) | `{base}/index.html` |
| **Установка** | `{base}/install.html` |
| Вкладка сделки | `{base}/tab.html` (привязывается при install) |

## 2. Локальное приложение на портале

**Разработчикам → Другое → Локальное приложение** (или приложение **388**)

| Поле | Значение |
|------|----------|
| Название | Заявка на договор |
| **Путь вашего обработчика** | `https://b24-contract-request.vercel.app/index.html` |
| **Путь для первоначальной установки** | `https://b24-contract-request.vercel.app/install.html` |
| Использует только API | Нет |
| Права (scope) | см. таблицу ниже |

### Права локального приложения (обязательно)

Отметьте **все четыре** — без `bizproc` БП 608 не запустится:

| Scope в REST | В интерфейсе Б24 (примерно) | Зачем |
|--------------|----------------------------|--------|
| **crm** | CRM | `crm.deal.get` — сделка во вкладке |
| **placement** | Встраивание приложений | `placement.bind` → вкладка `CRM_DEAL_DETAIL_TAB` |
| **bizproc** | Бизнес-процессы | `instances`, `task.list`, `task.complete` (шаблон **608**) |
| **user** | Пользователи | `user.current` — задания текущего пользователя |

**Не нужны** для этого проекта: `im`, `imbot`, `disk`, `landing`, `catalog`, `userfieldconfig`.

Пользователь, от имени которого создаётся приложение, должен иметь право **запускать** шаблон БП 608 и работать со сделками на ik-navigator.

### Входящий вебхук (опционально)

Нужен **только** если будете вызывать REST с сервера (скрипты, отладка без iframe).  
Вкладка в карточке работает через **локальное приложение** (BX24 JS SDK), отдельный вебхук для UI **не обязателен**.

Если создаёте вебхук на https://ik-navigator.bitrix24.ru/ :

| Параметр | Значение |
|----------|----------|
| Раздел | Разработчикам → Другое → **Входящий вебхук** |
| Пользователь | Админ или сотрудник с правом запуска БП 608 и доступом к сделкам |
| Права | Те же: **crm**, **placement**, **bizproc**, **user** |
| Хранение | `contract-request/.env` → `B24_WEBHOOK=` (не в git) |

Проверка после создания:

```http
POST https://ik-navigator.bitrix24.ru/rest/.../profile.json
POST .../bizproc.workflow.template.list.json
```

Сохранить → **Переустановить** → открыть `install.html` → дождаться «Готово».

## 3. Доступ для всех сотрудников

Вкладка «Заявка на договор» видна только тем, кому **разрешено приложение** и кто имеет **доступ к CRM / сделкам**.

### Приложение — всем на портале

Настраивает **администратор** на https://ik-navigator.bitrix24.ru/

1. **Приложения** → **Маркетплейс** → **Ещё** → **Установленные приложения**  
   (или **Разработчикам** → список локальных приложений → **Заявка на договор** / **388**)
2. **⋯** → **Доступ**
3. **Список должен быть пуст** — тогда приложение доступно **всем сотрудникам**  
   ([справка Битрикс24](https://helpdesk.bitrix24.ru/open/17398580/))
4. Если в списке есть отдельные люди/отделы — удалите всех (**×**), сохраните

Ошибка в консоли вкладки: `user_access_error` — у сотрудника нет доступа к приложению; проверьте пункт 3.

### CRM — права на сделки

Доступ к приложению **не заменяет** права CRM. Сотрудник должен видеть сделки воронок **продаж (8)** и **оформления (10)**:

**CRM** → **Настройки** → **Права доступа** → роль сотрудника → **Сделки** — чтение (и изменение, если нужно сохранять форму).

### Проверка от имени сотрудника

1. Войти под обычным пользователем (не админом)
2. CRM → Сделка → вкладка **«Заявка на договор»**
3. Если вкладки нет — **⋯** в ряду вкладок или **Ещё**

## 4. Проверка установки

1. CRM → любая сделка → вкладка **«Заявка на договор»**
2. Вкладка показывает активные процессы (608) и задания по сделке

## 5. Шаблон БП

Не создавать новый — использовать существующий:

https://ik-navigator.bitrix24.ru/crm/configs/bp/CRM_DEAL/edit/608/

На тестовом портале ID шаблона может отличаться — экспорт `.bpt` или ручная настройка.

## 6. Отладка

| Ошибка | Причина |
|--------|---------|
| `ACCESS_DENIED` | Нет scope `bizproc` |
| Вкладка пустая | Не завершена установка / нет `placement.bind` |
| Задания не видны | Проверить scope `bizproc` и права на шаблон 608 |
| `user_access_error` | В **Доступ** к приложению не добавлен сотрудник; очистите список (всем) или добавьте отдел |
| `insufficient_scope` | Добавить `bizproc` и переустановить приложение |
