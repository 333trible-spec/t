# Версии приложения «Заявка на договор»

Формат: **`v 0.6`**, **`v 0.61`**, … — шаг **+0.01**.

Текущая версия: `version.json` · в шапке вкладки справа.

## Команды в чате

| Фраза | Действие |
|-------|----------|
| **апдейт версии** | Снимок `versions/<версия>/` + deploy |
| **откат в версии v 0.5** | Восстановить снимок + deploy |

### «апдейт версии»

1. Читаем `version.json` (например `v 0.6`)
2. Если `versions/v 0.6/` уже есть → **«версия v 0.6 уже сохранена»**
3. Иначе: `npm run version:save`

### Следующая версия (+0.01)

```bash
npm run version:bump   # v 0.6 → v 0.61
```

Потом правки кода → **апдейт версии**.

### Откат

```bash
npm run version:rollback -- "v 0.5"
```

Старые снимки `0.5v` / `0.6v` тоже понимаются как `v 0.5` / `v 0.6`.

## npm

| Команда | Назначение |
|---------|------------|
| `npm run version:bump` | +0.01 в `version.json` |
| `npm run version:save` | Снимок + prod deploy |
| `npm run version:rollback -- "v 0.5"` | Откат + deploy |
| `npm run deploy` | Только deploy |
