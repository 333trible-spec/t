# Вариант Б — Сайт Б24 + userscript для подсветки

Вкладка приложения **сохраняет цвет в CRM**. Подсветка **всей карточки** — через **userscript** (или закладку).

> **Почему не только сайт:** страницы Сайтов Б24 публикуются на **`*.bitrix24shop.ru`**, а CRM — на **`*.bitrix24.ru`**. Iframe вкладки не может менять DOM карточки (разные домены). Это ограничение браузера, не баг кода.

---

## Шаг 1. Опубликовать страницы

```powershell
cd "Личное/Работа/bitrix24/deal-card-bg"
npm run site:publish
```

Скрипт выведет **реальный URL** (обычно `https://….bitrix24shop.ru/deal-card-bg/install/`).

---

## Шаг 2. Локальное приложение

1. **Приложения** → **Разработчикам** → **Фон карточки сделки** → **Изменить**
2. В **обработчик** и **установку** — URL из `site:publish` (оба поля одинаковые)
3. **Сохранить** → **Переустановить**

---

## Шаг 3. Подсветка карточки (один раз на ПК)

**Tampermonkey** → новый скрипт → вставить `userscript/deal-card-bg.user.js` → сохранить.

Скрипт:
- красит карточку при открытии сделки (по полю UF);
- слушает вкладку «Цвет фона» — смена цвета **сразу** без перезагрузки.

Без Tampermonkey: закладка из `bookmarklet/создать-закладку.html` (клик в карточке).

---

## Шаг 4. Проверка

1. CRM → сделка **17**
2. Вкладка **«Цвет фона»** → выбрать цвет
3. Фон карточки меняется (если userscript установлен)
4. Опционально: ⚙ → вид карточки → поле **«Цвет фона карточки»**

---

## Остановить

```powershell
npm run disable
```

---

## Для команды

- **Приложение** на портале — палитра и сохранение в CRM
- **Userscript** на ПК каждого менеджера — визуальная подсветка
- Туннель и сервер на ПК **не нужны**
