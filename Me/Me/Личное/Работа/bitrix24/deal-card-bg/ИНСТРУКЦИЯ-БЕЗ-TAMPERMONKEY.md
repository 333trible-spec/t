# Фон карточки сделки — без Tampermonkey

В облачном Б24 нельзя «включить фон» в настройках CRM. Варианты без расширений:

| Вариант | Кому | Визуал всей карточки | Сложность |
|---------|------|----------------------|-----------|
| **A. Только поле в CRM** | Вся команда | Нет — только значение в форме | ★☆☆ |
| **B. Закладка в браузере** | Только ты | Да, по клику | ★☆☆ |
| **C. Локальное приложение Б24** | Вся команда (с приложением) | Вкладка + цветная полоска в поле | ★★★ |
| **D. Маркетплейс** | ik-navigator | Зависит от приложения | ★★☆ |

---

## A. Только Битрикс24 (без кода в браузере)

Уже сделано: поле **«Цвет фона карточки»** (`UF_CRM_DEAL_CARD_BG`).

- Менеджер выбирает цвет в карточке → **Сохранить**
- В списке сделок — колонка и фильтр
- На канбане — цвет **плитки** штатно не меняется; используйте **стикеры** и **цвет стадии**

Подходит, если нужна **метка**, а не подсветка экрана.

---

## B. Закладка в браузере (рекомендую лично)

Без Tampermonkey, без сервера.

1. Откройте в браузере файл  
   `deal-card-bg/bookmarklet/создать-закладку.html`
2. Перетащите синюю кнопку **«B24: подсветить фон»** на панель закладок
3. На портале откройте **карточку сделки** (URL вида `…/crm/deal/details/123/`)
4. Нажмите закладку — фон подтянется из поля

**Минус:** после смены цвета нужно снова нажать закладку или F5.  
**Плюс:** ничего не устанавливается, работает в Chrome / Edge / Firefox.

## C. Локальное приложение Б24 (для команды на тесте)

Официальный способ: вкладка **«Цвет фона»** в карточке сделки + опционально виджет-поле с цветной полосой.

### Что нужно

- Публичный **HTTPS**-адрес (туннель cloudflared или хостинг)
- Регистрация **локального приложения** на портале

### 1. Запустить сервер

```powershell
cd "Личное/Работа/bitrix24/deal-card-bg"
npm run app:start
```

Сервер: `http://127.0.0.1:3847`

### 2. Туннель HTTPS

В **другом** окне PowerShell:

```powershell
cloudflared tunnel --url http://127.0.0.1:3847
```

Скопируйте URL вида `https://xxxx.trycloudflare.com` — это **базовый URL приложения**.

### 3. Локальное приложение на портале

1. `b24-s2an91.bitrix24.ru` → **Приложения** → **Разработчикам** → **Другое** → **Локальное приложение**
2. Название: `Фон карточки сделки`
3. **Путь вашего обработчика:** `https://xxxx.trycloudflare.com/install.html`
4. **Путь для первоначальной установки:** тот же URL
5. Права: **CRM**, **Встраивание приложений (placement)**, **Настройки пользовательских полей**
6. Сохранить → **Установить**

Откроется страница установки — должны появиться зелёные пункты (поле, вкладка).

### 4. В карточке сделки

- Вкладка **«Цвет фона»** — палитра и превью, сохраняет в `UF_CRM_DEAL_CARD_BG`

**Важно:** туннель cloudflared живёт, пока открыто окно. Для постоянной работы — VPS или хостинг со статикой.

### 5. Фон всей формы для всех

Облако не даёт приложению красить родительскую страницу. Для **полной** подсветки без Tampermonkey у каждого пользователя:

- закладка (вариант B), или  
- позже — приложение в **Маркете** с нужными правами на ik-navigator

---

## D. Маркетплейс (прод ik-navigator)

На **Энтерпрайз** с подпиской Маркет можно подобрать готовое приложение («цвет сделок», «подсветка CRM»). Проверять на **тестовом** портале перед продом.

---

## Что выбрать

- **Быстро только себе** → закладка (B)  
- **Команда, без расширений** → локальное приложение (C) + поле в виде карточки  
- **Только учёт цвета** → вариант A, роботы по стадиям  

Tampermonkey по-прежнему в `userscript/` — если передумаете, он красит фон **автоматически** при каждом открытии сделки.
