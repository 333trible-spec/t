# Фон карточки сделки — Битрикс24

Настройка для **облачного** портала: поле «Цвет фона» в CRM + опциональный userscript для визуальной подсветки.

> В облаке **нет** штатной кнопки «поменять фон карточки». Мы храним цвет в пользовательском поле и (по желанию) красим интерфейс скриптом в браузере.

**Портал для тестов:** `b24-s2an91.bitrix24.ru`  
**Прод:** `ik-navigator` — только после проверки на тесте.

---

## 1. Установка поля (один раз)

Из папки проекта:

```powershell
cd "Личное/Работа/bitrix24/deal-card-bg"
npm run setup
```

Создаётся поле **`UF_CRM_DEAL_CARD_BG`** — список цветов:

| Значение | Фон |
|----------|-----|
| Без фона | — |
| Бронь | тёплый жёлтый |
| Оформление | голубой |
| Рассрочка | сиреневый |
| VIP | золотистый |
| Срочно | розовый |
| Успех | зелёный |
| Провал | серый |

Палитра правится в `lib/colors.js`, затем снова `npm run setup`.

---

## 2. Показать поле в карточке

1. CRM → **Сделки** → открыть любую сделку  
2. **⚙ → Настройка вида карточки** (или «Настройки» → «Настройка вида карточки»)  
3. Перетащить **«Цвет фона карточки»** в нужный раздел (удобно — вверх, рядом со стикерами)  
4. Сохранить  

Повторить для воронки **«Продажа недвижимости»**, если вид карточки отдельный.

## 3. Визуальный фон

**Без Tampermonkey** — см. **`ИНСТРУКЦИЯ-БЕЗ-TAMPERMONKEY.md`**:

| Способ | Суть |
|--------|------|
| **Закладка** | `bookmarklet/создать-закладку.html` — перетащить кнопку в браузер |
| **Локальное приложение** | `npm run app:start` + cloudflared + вкладка «Цвет фона» в сделке |
| **Только поле** | Цвет в CRM без подсветки экрана |

С Tampermonkey (автоматически при открытии сделки): `userscript/deal-card-bg.user.js`

---

## 4. Сменить цвет вручную

В карточке сделки: поле **«Цвет фона карточки»** → выбрать значение → **Сохранить**.

Или из терминала:

```powershell
npm run set-color -- 21 "Бронь"
```

(`21` — ID сделки)

---

## 5. Автоцвет при смене стадии (робот)

CRM → Сделки → воронка → стадия → **Роботы** → **Изменить поле**:

| Стадия | Поле | Значение |
|--------|------|----------|
| Консультация / Показ | Цвет фона карточки | Оформление |
| Бронь | Цвет фона карточки | Бронь |
| Оформление | Цвет фона карточки | Рассрочка |
| Сделка успешна | Цвет фона карточки | Успех |
| Сделка провалена | Цвет фона карточки | Провал |

Роботы настраиваются **в интерфейсе** портала — REST-скрипт их не создаёт (зависит от ID стадий на конкретном портале).

---

## 6. Канбан

На канбане фон **плитки** штатно не меняется. Работает:

- цвет **полоски стадии** (CRM → Настройки → Стадии воронки)  
- поле **Стикеры** (`UF_CRM_DEAL_STICKERS`) на лице карточки  
- фильтр по полю **«Фон карточки»** в списке сделок
