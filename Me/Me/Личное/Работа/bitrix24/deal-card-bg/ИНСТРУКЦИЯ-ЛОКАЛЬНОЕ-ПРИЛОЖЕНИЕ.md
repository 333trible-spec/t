# Локальное приложение Б24 — «Фон карточки сделки»

**Архитектура:** Node-сервер на ПК + HTTPS-туннель + локальное приложение на портале.  
**Без Tampermonkey и закладок** — цвет виден через **виджет поля** в карточке сделки.

Портал: **b24-s2an91.bitrix24.ru** (тест).

---

## Как это работает

| Часть | Где | Зачем |
|-------|-----|--------|
| **Node-сервер** | ПК, порт **3848** | Отдаёт `install.html`, `tab.html`, `field-handler.html` |
| **cloudflared** | ПК | HTTPS-URL для портала Б24 |
| **Локальное приложение** | Портал | Вкладка «Цвет фона» + тип поля-виджета |
| **Поле в карточке** | CRM | Цветная полоска с названием («Бронь», «VIP»…) |

> Облачный Б24 **не даёт** перекрасить всю карточку с внешнего URL — ограничение iframe. Виджет поля — штатный способ кастомизации без браузера.

## Быстрый старт

```powershell
cd "Личное/Работа/bitrix24/deal-card-bg"
npm run start
```

Команда поднимает сервер и туннель, выводит URL вида:

```text
https://xxxx.trycloudflare.com/install.html
```

## Настройка на портале (один раз)

1. **Приложения** → **Разработчикам** → **Локальное приложение** → **Фон карточки сделки**
2. **Обработчик** и **Установка** — URL из консоли (оба одинаковые)
3. **Права (scope)** — отметьте **все три**:
   - `crm`
   - `placement`
   - `userfieldconfig` ← **обязательно**, без него виджет не регистрируется
4. **Сохранить** → **Переустановить**

На установке — **зелёные** пункты: тип поля `deal_card_bg`, поле переведено на виджет, вкладка.

Красная ошибка про `userfieldconfig` → добавьте scope и переустановите снова.

## Поле в карточке

1. CRM → любая **сделка** → ⚙ **Настройка** → **Просмотр**
2. Перетащите **«Цвет фона карточки»** на форму → **Сохранить**

В карточке — **цветная полоска** с подписью. В режиме редактирования — палитра.

---

## Проверка

1. `npm run start` — сервер и туннель **ON**
2. Сделка **17** → поле «Цвет фона карточки» → выберите **«Бронь»**
3. Полоска жёлтая; вкладка **«Цвет фона»** — та же палитра для команды

## Команды

| Команда | Действие |
|---------|----------|
| `npm run start` | Сервер + туннель + URL |
| `npm run app:start` | Только сервер (3848) |
| `npm run tunnel` | Только туннель |
| `npm run app:status` | Статус |
| `npm run app:stop` | Остановить всё |
| `npm run disable` | Выключить сайт на портале (если использовали вариант Б) |

---

## Если вкладка не открывается

- Запущены `npm run start` и процессы живы (`npm run app:status`)
- URL в приложении **совпадает** с `.tunnel-url` (меняется при каждом `tunnel`)
- Happ/VPN иногда рвёт туннель — отключите VPN и повторите `npm run tunnel`

---

## Для команды

- На портале: права на приложение «Фон карточки сделки»
- На ПК: **один** сервер (ваш или VPS) с постоянным доменом — для прода **ik-navigator** не трогаем без согласования
- Tampermonkey **не нужен**

---

## Вариант «Сайт Б24» (устарел для подсветки)

`npm run site:publish` — сохраняет цвет в CRM, но **не красит** карточку (домен `bitrix24shop.ru` ≠ CRM). Используйте **локальный сервер**.
