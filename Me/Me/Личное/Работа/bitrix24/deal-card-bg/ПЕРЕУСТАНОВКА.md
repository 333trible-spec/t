# Переустановка — если цвет не меняется / белый экран / скачивается install.html

**Не используйте URL с Диска Б24** (`download/?token=…`) — отдаёт `attachment`, браузер скачивает файл вместо iframe. Используйте Vercel (`static-urls.json`) или localtunnel.

## Вариант А — Vercel (рекомендуется для Б24)

**GitHub Pages не подходит:** при установке Битрикс24 шлёт **POST** → GitHub отвечает **405 Not Allowed**.

```powershell
cd "Личное/Работа/bitrix24/deal-card-bg"
npm run publish:github
npx vercel login          # один раз
npm run publish:vercel
npm run verify
```

URL для Б24: `https://<проект>.vercel.app/install.html` (из вывода скрипта).

Или: [vercel.com/new](https://vercel.com/new) → Import `333trible-spec/t` → Deploy.

## Вариант Б — туннель (разработка)

```powershell
npm run start
npm run verify
```

Скопируй URL из консоли, например `https://….loca.lt/install.html`.

## 1. Настройки приложения

`b24-s2an91.bitrix24.ru` → **Приложения** → **Разработчикам** → **Фон карточки сделки** → **Изменить**

| Поле | Значение |
|------|----------|
| **Обработчик** | `https://tt-two-lime.vercel.app/app.html` |
| **Установка** | `https://tt-two-lime.vercel.app/install.html` |
| Scope | **crm** + **placement** + **userfieldconfig** |
| Использует только API | **выкл** |

**Сохранить.**

## 2. Переустановить (обязательно)

**Переустановить** (не только «Сохранить»).

Должна открыться страница **«Фон карточки сделки»** со списком зелёных пунктов:

- тип поля / обработчик виджета  
- поле `UF_CRM_DEAL_CARD_BG`  
- вкладка `CRM_DEAL_DETAIL_TAB`  

**Красный текст** — скопируй в чат.

## 3. Поле в карточке

Сделка → ⚙ → **Просмотр** → поле **«Цвет фона карточки»** → **Сохранить**.

В карточке — **палитра цветов**, не пустое поле.

## Что должно работать после переустановки

- **Вся карточка** перекрашивается при открытии сделки (фоновый worker + поле-виджет)
- **Поле-виджет** — палитра и цветная полоска
- **Вкладка** «Цвет фона»
