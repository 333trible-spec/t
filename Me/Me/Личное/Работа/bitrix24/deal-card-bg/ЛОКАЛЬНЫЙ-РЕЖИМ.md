# Локальный режим для тестов (без Vercel)

Облачный Битрикс24 **не видит** `localhost` — нужен HTTPS-туннель с ПК.  
«Стабильно локально» = **фиксированный URL** + **watchdog** (сам переподнимает туннель).

## Запуск

```powershell
cd "Me/Me/Личное/Работа/bitrix24/deal-card-bg"
npm run start
npm run verify
```

Стабильный URL (не меняется при перезапуске):

`https://b24-deal-card-bg-s2an91.loca.lt/install.html`

Один раз вставьте в Б24 → **Обработчик** и **Установка** → Сохранить → Переустановить.

## Проверки

| Команда | Что проверяет |
|---------|----------------|
| `npm run verify:local` | только `127.0.0.1:3848` |
| `npm run verify` | туннель GET + POST |
| `npm run app:status` | сервер / туннель / URL |

## Что должно быть включено

- ПК не выключать (или сон отключить на время теста)
- `npm run app:status` → App ON, Tunnel ON, Watchdog в `start` поднимается сам
- VPN (Happ) лучше **выключить** — рвёт туннель

## Если туннель упал

Watchdog перезапустит его **с тем же URL** (фиксированный поддомен в `local-dev.json`).

```powershell
npm run app:status
npm run verify
```

Обновлять URL в Б24 **не нужно**, если поддомен тот же.

## Настройка поддомена

Файл `local-dev.json`:

```json
{ "subdomain": "b24-deal-card-bg-s2an91" }
```

Если поддомен занят — смените имя и снова `npm run start`.

## Ограничения

| Работает | Не работает |
|----------|-------------|
| Тесты на портале, пока ПК включён | ПК выключен / сон |
| Тот же URL после перезапуска | 100% аптайм (сервис localtunnel иногда лежит) |

Для продакшена без ПК — позже **Vercel** (`npm run publish:vercel`).
