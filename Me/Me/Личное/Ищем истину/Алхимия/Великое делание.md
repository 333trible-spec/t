# Великое делание

## Magnum opus

Четыре этапа в одной цепи (варианты названий):

1. **Nigredo** — putrefactio
2. **Albedo** — ablution
3. **Citrinitas** (не всегда)
4. **Rubedo** — coniunctio, lapis philosophorum

## Lapis philosophorum

**Философский камень** — не только «золото из свинца», а:
- универсальный растворитель;
- медицина (эликсир);
- символ **целостности** (Юнг).
