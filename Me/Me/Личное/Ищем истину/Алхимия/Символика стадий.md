# Символика стадий

## Повторяющиеся образы

| Образ | Значение |
|-------|----------|
| **Ворон / воронка** | Nigredo, смерть материи |
| **Лебедь / луна** | Albedo, чистота |
| **Король и королева** | Сульфур и ртуть, активное/пассивное |
| **Дракон** | Прайма материя, страсть, Mercurius |
| **Феникс** | Воскресение после сожжения |
| **Оuroboros** | Цикл, единство начала и конца |
| **Древо** | Рост, дистилляция соков |

## Где смотреть

2. Сопоставь таблице выше.
3. Запиши **личную** ассоциацию отдельно (I).
