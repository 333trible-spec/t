# Алхимические гравюры

← [[../Ищем истину]] · [[../../Me|Me]] · [[../Prisca sapientia|Prisca sapientia]]

> [!abstract] Главная идея
> Гравюры — **визуальный учебник** без слов (или с минимумом текста): опиши (F) → расшифруй символы (S) → свяжи с опытом (I). Каждая заметка = **образ + декодинг**.

## Как читать любую гравюру

1. **Описание** — что буквально на картине (F).
2. **Символы** — таблица элементов (S).
3. **Декодинг** — исторический + психологический (I).
4. **Связь** — стадия nigredo/albedo/rubedo, текст.
